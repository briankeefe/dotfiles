Hyprland Cheat Sheet

Super = Windows key. Shortcuts for the current Omarchy-derived session.
Log out without shutting down: Super + Escape, then choose Log out. This runs uwsm stop. Save your work first.

Applications

Super + EnterTerminal · Ghostty
Super + SpaceApplications · Fuzzel
Also Super + Alt + Space
Super + EFiles · Dolphin
Super + BBrowser · Chrome
Super + TTheme switcher

Workspaces

Super + 1–0Switch workspace · 1–9, 0 for 10*
Super Shift + 1–0Move window to workspace*
Super + TabNext workspace
Super Shift + TabPrevious workspace
Super + SToggle scratchpad

Window control

Super + ← ↓ ↑ →Focus in arrow direction
Super Shift + ← →Move window horizontally; at a tiled edge, cross to the configured adjacent monitor
Super Shift + ↑ ↓Move window up / down
Super + Q / WClose window
Super + FFullscreen
Super Alt + SToggle split orientation
Alt + TabNext window
Super + Left dragMove window
Super + Right dragResize window

Session and desktop

Super + EscapeSystem menu
Lock, Log out, Suspend, Reboot, Shut down
Super + LLock screen · stays logged in
Super + PrintScreenshot display
Super Shift + SScreenshot region
Super Ctrl + EEmojis
Super Ctrl + AAudio panel
Super Ctrl + BBluetooth panel
Super Ctrl + WNetwork panel
Super Ctrl + PBattery / power panel
Unavailable on this desktop: requires a detected battery. For logout or shutdown, use Super + Escape.

Media and hardware keys

Volume up / downAdjust volume by 5%; up is capped at 150%
Mute / Mic muteToggle output / microphone mute
PlayPlay / pause
Next / PreviousNext / previous track
Brightness up / downAdjust brightness by 5%

Dedicated hardware keys, no Super required. These bindings also work while locked.

Notes

●*Number-row shortcuts are configured using physical keycodes, but the live binding list currently reports empty keys for these entries. Treat them as configured, not verified working.
●Super + M has no binding. Use the system menu to log out.
●The older Ctrl+Super summon shortcuts, Alt+number workspaces, and float/re-tile workspace shortcuts are not active in this session.
●This is a static reference, not a live view. Inspect loaded shortcuts with hyprctl binds.
